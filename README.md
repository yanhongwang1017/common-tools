# 常用工具合集

一个纯静态的前端工具集合，直接在浏览器中打开即可使用，无需安装依赖或启动服务器。

## 项目结构

```
.
├── index.html              # 入口页面：左侧菜单 + 右侧工具展示区
├── README.md               # 项目说明
├── rgbToHex/
│   └── index.html          # RGB 转 Hex 颜色转换器
├── imageCompressor/
│   └── index.html          # 图片压缩工具
└── urlCodec/
    └── index.html          # URL 编码/解码工具
```

## 使用方法

直接用浏览器打开项目根目录下的 `index.html` 文件。

- 左侧为工具菜单，点击即可切换右侧展示的工具。
- 每个工具独立存放在自己的文件夹中，便于后续扩展。
- 入口页会自动记住上次使用的工具，刷新页面后会恢复到该工具。

## 已集成的工具

### 1. RGB 转 Hex

将 RGB 颜色值转换为十六进制颜色代码。

- 支持分别输入 R、G、B 三个通道的值。
- 支持直接粘贴 RGB 字符串，例如 `102, 126, 234` 或 `rgb(102, 126, 234)`。
- 实时预览颜色并显示 HEX 结果。
- 一键复制 HEX 值。

### 2. 图片压缩

压缩图片文件，减小体积。

- 支持点击上传或拖拽上传。
- 可调整压缩质量（10% ~ 100%）。
- 实时显示原图、压缩后的预览对比。
- 显示原图大小、压缩后大小和压缩率。
- 支持自定义下载文件名，默认使用原文件名。
- 对 PNG 图片会自动在“保持 PNG 格式”和“转为 JPEG 格式”之间选择更小的结果。

### 3. URL 编解码

对文本进行 URL 编码或解码。

- 支持一键编码和解码。
- 支持复制结果。
- 支持将结果转回输入框，方便连续操作。

## 如何新增工具

1. 在项目根目录新建工具文件夹，例如 `newTool/index.html`。
2. 在根目录 `index.html` 的 `tools` 数组中添加一项：

   ```js
   { id: 'newTool', name: '新工具名称', path: './newTool/index.html' }
   ```

3. 刷新页面，左侧菜单会自动显示新工具。

## 技术说明

- 纯 HTML + CSS + JavaScript，无框架、无构建步骤。
- 单文件工具，均可独立打开运行。
- 使用 `iframe` 在入口页中加载各个工具，保持工具之间的隔离和独立维护性。
