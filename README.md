# 常用工具合集

一个纯静态的前端工具集合，直接在浏览器中打开即可使用，无需安装依赖或启动服务器。

## 项目结构

```
.
├── index.html              # 入口页面：左侧菜单 + 右侧工具展示区
├── README.md               # 项目说明
├── rgbToHex/
│   └── index.html          # RGB 转 Hex 颜色转换器
├── imageCompressor/
│   └── index.html          # 图片压缩工具
├── urlCodec/
│   └── index.html          # URL 编码/解码工具
├── jsonFormatter/
│   └── index.html          # JSON 格式化/压缩工具
├── base64Codec/
│   └── index.html          # Base64 编码/解码工具
├── gradientGenerator/
│   └── index.html          # CSS 渐变背景生成器
├── shadowGenerator/
│   └── index.html          # CSS 阴影生成器
├── svgCompressor/
│   └── index.html          # SVG 压缩工具
└── cssToWindi/
    └── index.html          # CSS 转 WindiCSS 类名工具
```

## 使用方法

直接用浏览器打开项目根目录下的 `index.html` 文件。

- 左侧为工具菜单，点击即可切换右侧展示的工具。
- 每个工具独立存放在自己的文件夹中，便于后续扩展。
- 入口页会自动记住上次使用的工具，刷新页面后会恢复到该工具。

## 已集成的工具

### 1. RGB 转 Hex

将 RGB 颜色值转换为十六进制颜色代码。

- 支持分别输入 R、G、B 三个通道的值。
- 支持直接粘贴 RGB 字符串，例如 `102, 126, 234` 或 `rgb(102, 126, 234)`。
- 实时预览颜色并显示 HEX 结果。
- 一键复制 HEX 值。

### 2. 图片压缩

压缩图片文件，减小体积。

- 支持点击上传或拖拽上传。
- 可调整压缩质量（10% ~ 100%）。
- 实时显示原图、压缩后的预览对比。
- 显示原图大小、压缩后大小和压缩率。
- 支持自定义下载文件名，默认使用原文件名。
- 对 PNG 图片会自动在“保持 PNG 格式”和“转为 JPEG 格式”之间选择更小的结果。

### 3. URL 编解码

对文本进行 URL 编码或解码。

- 支持一键编码和解码。
- 支持复制结果。
- 支持将结果转回输入框，方便连续操作。

### 4. JSON 格式化

格式化或压缩 JSON 字符串。

- 支持 2 空格、4 空格、Tab 缩进。
- 支持一键压缩为一行。
- 自动检测 JSON 语法错误并提示。

### 5. Base64 编解码

在普通文本与 Base64 之间转换。

- 支持文本编码为 Base64。
- 支持 Base64 解码为文本。
- 支持复制结果。

### 6. 渐变背景生成器

生成 CSS 渐变背景代码。

- 支持线性渐变和径向渐变。
- 可调整角度、起始颜色、结束颜色。
- 实时预览并生成 CSS 代码。
- 支持随机颜色和复制 CSS。

### 7. 阴影生成器

生成 CSS `box-shadow` 代码。

- 可调节水平/垂直偏移、模糊半径、扩散半径。
- 支持自定义阴影颜色和透明度。
- 实时预览并复制 CSS。

### 8. SVG 压缩

压缩 SVG 代码，减小文件体积。

- 移除注释、换行和多余空白。
- 显示原始大小、压缩后大小和压缩率。
- 支持复制压缩后的 SVG。

### 9. CSS 转 WindiCSS

将原生 CSS 样式代码转换为 WindiCSS / Tailwind 类名。

- 支持整段选择器块、内联声明等多种 CSS 输入格式。
- 智能尺寸单位换算（如 `16px` -> `4`，`10px` -> `2.5`）与任意值（如 `w-[135px]`）生成。
- 涵盖 Flexbox、Grid、间距尺寸、字体排版、颜色背景、边框圆角、阴影特效等完整属性。
- 提供属性逐条转换对照表及换算原理解析，辅助快速上手 WindiCSS。
- 支持纯类名、`class="..."`、`className="..."` 多种输出格式切换与一键复制。
- 内置经典样式模板（Flex居中、主按钮、徽章、毛玻璃、Grid网格）与实时渲染预览。

## 如何新增工具

1. 在项目根目录新建工具文件夹，例如 `newTool/index.html`。
2. 在根目录 `index.html` 的 `tools` 数组中添加一项：

   ```js
   { id: 'newTool', name: '新工具名称', path: './newTool/index.html' }
   ```

3. 刷新页面，左侧菜单会自动显示新工具。

## 技术说明

- 纯 HTML + CSS + JavaScript，无框架、无构建步骤。
- 单文件工具，均可独立打开运行。
- 使用 `iframe` 在入口页中加载各个工具，保持工具之间的隔离和独立维护性。
